# Composite Material Accounting

One electronic component contains one iron unit and one copper unit. Item count
alone is therefore not a conservation measure.

Iron accounting includes iron resources, ore, plates, refinery material,
assembler iron input, assembler in-process material, and every component in an
assembler output, belt, or storage. Copper accounting mirrors this with copper
resources, ore, plates, and assembler copper input.

During assembler processing, the recipe contributes one unit to each elemental
total. A completed or transported component also contributes one unit to each.
Tests check both totals at every pipeline phase.
